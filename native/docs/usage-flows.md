# 使用流程

原生测试版采用按当前状态提供入口的方式引导，不展示常驻教程或强制向导。

| 阶段 | 用户入口 | 完成与恢复 |
| --- | --- | --- |
| 首次打开 | Ballance 页提供选择已有游戏、下载并安装 | 游戏未选中时，资源和配置页同样提供入口；资源页仍可以打开资源站 |
| 选择已有游戏 | 原生目录选择框 | 校验游戏主目录；目录不可用时显示可操作的恢复页，保留原有语言及外观偏好 |
| 安装游戏 | 下载 → 安装；首次页面可直达 | 选择空文件夹；默认包含 NewPlayer 与 BML+，选项遵守依赖关系；后台任务显示进度、取消、失败重试；成功后有进入游戏入口 |
| 启动游戏 | Ballance 页 START | 原版文件有改动时提供选择；启动状态、自己启动的游戏停止操作沿用同一原版字体按钮 |
| 获取资源 | 资源页独立切换在线／本地，再选择资源类型 | 在线支持搜索、封面、说明和安装；本地提供导入；空目录显示获取方式，缺少加载器时可直达安装支持；社区网站保留外部入口 |
| 网站一键安装 | 资源空列表或设置中启用一键安装 | 仅显式点击时关联当前程序；已关联后可由网站唤起，后台下载有任务记录；网络失败可重试 |
| 修改配置 | 配置 → 参数 → 游戏设置或某个模组配置 | 游戏参数统一分组，键位默认收起，搜索跨组展示；手动保存，切换/重新读取前确认未保存修改 |
| 配置异常 | 配置页重新读取、选择其他配置 | 读取失败不展示上一份文件的字段；保存前校验并检查并发修改，合并保存采用同一批次备份与回滚 |
| 管理资源 | 列表主要动作与右键菜单 | 文件右键可改名、移动、删除；空白处右键可新建文件夹和打开目录；进入子目录才显示路径导航；保留预览、启停及撤销删除 |

验证包括隔离配置下的首次打开、失效目录恢复、无资源与缺少加载器、游戏配置合并、键位展开与搜索、按关卡编辑排行榜、模组分组、菜单及两种配色。合并保存通过真实 Database.tdb 数据验证，覆盖两文件保存、第二文件无效时不写入第一文件、保留外部未编辑修改、原版 Player 不显示无效 INI 参数。

本轮不重新执行真实游戏下载，也不在验收时修改系统的协议关联；下载与协议唤起沿用已有实现，协议启用入口及只读状态检查已接入。


本轮控件调整：设置和配置统一字段行高，开关保留原有 0/1 编码，说明改为虚线下划线和鼠标旁悬停提示，存档按关卡展开编辑排名。界面与鼠标交互由用户测试，交付前只做编译和逻辑检查。
