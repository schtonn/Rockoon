# Rockoon 原生桌面版

Rust + Iced 0.14，使用 tiny-skia 软件渲染。运行不依赖 Tauri、WebView2、JavaScript 或 wgpu。
当前版本为 0.2.0；Windows 是本机验证平台，macOS 继续作为实验平台。

## 界面

- 左侧仅保留 Ballance、资源、配置、下载、设置；资源用在线/本地与类型分别筛选，制图作为资源页内入口，配置分游戏/选项/存档/配置集，下载只显示任务。
- Ballance 页的原版天空纹理铺满内容区高度；游玩按钮直接使用游戏原版菜单图集，START / STOP / STARTING… 从该目录的原版 Font_1.tga 字库提取，按原菜单的首字母及小型大写字形组合；统一为 11px 高，在整个按钮上居中。
- 右上角文件夹图标展开“打开目录 / 更改目录”两个纯文字选项，旁边显示目录路径；首页仅保留原版 START，游戏组件从配置 → 游戏进入。
- 按钮有悬停与按下反馈；START 使用原版正常/选中纹理，140ms 平滑切换。动画由控件按需绘制，不触发整个页面逐帧重建，静止后不再请求刷新。
- 设置中可以即时切换浅色 / 深色并保存；旧配置默认保持深色。两种模式均使用中性黑白灰，覆盖侧栏、输入框、下拉框、复选框、滑块、菜单和通知；游戏本身的纹理保留原色。TAS 新窗口继承主窗口的外观，其编辑偏好仍单独保存。
- 资源右键菜单与下拉列表使用浮层，不挤动正文；点击外部、滚动外部或 Esc 关闭。
- 普通消息在右下角悬浮约 5 秒，错误约 8 秒，开头 0.16 秒淡入、最后 0.3 秒淡出；通知清除后停止通知定时刷新。确认对话框仍等待用户选择。
- 首次打开直接提供“选择已有游戏 / 下载并安装”；记忆目录失效时保留恢复提示和操作入口，不依赖会消失的通知。
- 资源页右上提供社区资源站入口，并在空列表中提示本地导入及一键安装；缺少 BML/BML+ 时可直接跳到安装页。访问资源站时先探测可用域名；协议关联仅在用户点击启用时写入，不在启动时抢占其他安装的处理程序。
- 游戏设置合并 Database.tdb 与适用的 Player.ini，按常规、画面、声音、键位与相机、高级显示；键位与高级默认收起，搜索自动显示匹配分组。方向键按两列排列，分辨率合为一行、音量显示百分比。模组配置只选择一次文件，内部各组使用展开区块，不显示“配置来源”或额外说明。
- 合并配置先校验并编码全部修改，再统一备份和写入；不会覆盖没有编辑的另一份文件。配置读取失败时提供重试，修改在短暂延迟后自动保存，切换配置、启动游戏或退出前先完成写入。
- TAS 在独立原生窗口中打开，设置页可直接打开，无需先启用。
- BML、相机工具和调试工具的已知配置字段使用中文名称，保留原文件的键名和数值格式；第三方未知字段保留原名。
- 保存配置的页签名为“配置集”，正文用一句话介绍保存范围；设置页的纯文字行和带控件的行统一为 36px。
- 首次使用的两个按钮固定为相同的 40px 高度；输入框、下拉框、Tab 和资源卡片采用半透明背景。
- 常规操作按钮使用细边框，导航和展开行保留轻量反馈；在线/本地及配置页签有整体外框，虚线字段的说明在悬停时立即显示。
- 天空盒不再常驻目标选择器；在线安装、资源包导入和单张天空贴图导入识别到天空内容后才弹窗选关卡，取消不会写入天空文件。
- “游戏”页按当前目录展示 Ballance 及已安装的 NewPlayer、BML/BML+，不显示未安装项或把不同构建当成多个组件。组件名称提供一致的简短悬停说明，NewPlayer 为“修复兼容问题”，BML/BML+ 为“加载地图和模组”；编辑弹窗不再重复说明，游戏卡片只保留一个“编辑”按钮。Windows 优先读取 EXE/DLL 的版本资源，缺少时回退到该目录的安装记录，仍无法识别时如实显示“版本未识别”。
- 组件与历史版本仅在“编辑”弹窗中选择，默认构建、备用构建与旧版加载器都在这里；切换组件及取消会使旧的版本请求失效。查看游戏页只扫描本地文件，不等待下载站。
- 新游戏的勾选项共享组件名称上的悬停说明，BML+ 的勾选自动包含 NewPlayer；安装结束自动回到游戏页，“浏览地图和模组”进入本地资源。
- Tab 固定 32px 高，内圆角 4px、外圆角 6px、内边距 2px；横线留出上下空隙，本地文件及在线资源的大小靠右对齐。
- 首页之外的内容区沿用当前选择的首页天空，使用缓存的模糊底图，浅色模式图像不透明度 20%、深色模式 14%；背景缩放铺满内容区，控件和弹层保持清晰，缺少天空时沿用纯色背景。
- 设置中的首页背景直接用缩略图选择并持久保存，不显示关卡名称，缺失的天空不展示。
- 本地资源恢复为 34px 紧凑列表，一次显示全部搜索结果，文件大小靠右，模组用开关启停，保留双击和右键操作；在线保留封面卡片与服务端查询分页。
- 只有已知运行器/加载器的 `source_key` 才跳到游戏配置，其他 `x-patch` 走资源包安装、备份和安装记录，并在本地组件与补丁中展示名称和版本。
- 配置集页只保留“新配置集”，切换或新建时保存当前配置集的修改，避免把普通修改另存成一份新配置集。
- 自动保存不打断输入，不弹出成功通知；无效数字保留在输入框并显示错误，不写入磁盘。后台写入期间的新修改会接续保存。
- 已修改的字段旁显示无边框撤销箭头，恢复进入当前配置时的值，自动保存后仍可撤销；重新读取或再次进入配置时更新这个基准，不提供整页恢复默认。
- 存档的开关统一标为“解锁”，排行榜编辑同样自动保存。
- 自制地图承载关卡只在 BML 的 CustomMap 配置中选择，启动器启动地图也读取同一项；色深使用 16/32 位下拉选择，旧启动器关卡偏好仅作缺少加载器配置时的兼容回退。
- 原版游戏与 CFG 的 K 类型字段统一为点击后按键录入，Esc 取消，失去窗口焦点或切换文档也取消，重复按键不重复写入。录入控件先拦截键盘事件，避免 Tab、空格等操作其他控件；普通 I/F 数值字段保持输入框。原版键位保存内部 0–71 编号，模组键位保存 CKKEYBOARD/DirectInput 扫描码，左右修饰键与小键盘单独识别。
- 任务按进行中、已完成排列，已完成记录下方的居中 X 清理完成项，进行中的任务保留。
- 没有辅助灰色小字、宣传卡片或重绘的游戏插画。

Windows 软件渲染使用 `vendor/iced_tiny_skia` 的局部补丁，每次请求绘制时重绘整个窗口，避开文字替换时的局部损伤遗漏；不会让静止窗口持续刷新，其他平台保留上游绘制路径。代价是动画期间的软件绘制工作量增加，实际残影和响应表现仍需在用户机器验证。上游来源、MIT 许可证和修改位置见该目录的 `ROCKOON.md`。

正文内嵌思源黑体 CN Regular，导航使用 Medium（15px）；无需在系统中安装字体。
字体来自 Adobe Source Han Sans 2.005R，原始字体、OFL 许可证和来源哈希见 native/resources/fonts/。

## macOS 首次使用

解压 macOS 包，将 Rockoon.app 放进“应用程序”后打开，先选择已有的 Ballance 文件夹或下载游戏。
首页随后显示运行环境引导，Apple 芯片缺少 Rosetta 2 时先点击安装并完成系统授权，再初始化游戏环境。
内置 Wine 随发行包提供，初始化会解压并准备游戏运行所需的环境，进度在任务页显示，完成后返回首页。
也可以选择已有 Wine，启动器会使用它初始化环境，不要求同时存在内置 Wine。
设置中的“游戏运行环境”显示当前 Wine 和就绪状态，更换 Wine、恢复内置 Wine 和高级设置都在这一组中。

“资源站安装链接”只负责让浏览器的安装链接打开 Rockoon，软件内的搜索和安装无需启用它。
关联操作在 macOS 上会注册应用并设置实际的系统链接处理程序，启动时只读取当前关联状态。

本地天空盒按同目录的 Sky_名称_Front/Back/Left/Right/Down.bmp 分组，组行预览整个天空盒，展开后管理各张图片。
本地文件行的竖向更多按钮与右键打开同一菜单。天空盒预览支持滑块实时调整和直接拖动视角，连续操作只排队最新视角，松手后恢复完整清晰度。

## 构建和运行

Windows 安装 Rust stable（最低 1.88）和 Visual Studio C++ Build Tools：

~~~powershell
cargo run --manifest-path native/Cargo.toml
cargo build --release --manifest-path native/Cargo.toml
~~~

输出为 native/target/release/rockoon-native.exe，复制使用时请同时保留随包的 Rockoon-SourceHanSans-LICENSE.txt。
命令行可传入游戏根目录，不改写已保存的目录选择：

~~~powershell
.\rockoon-native.exe "D:\Games\Ballance"
~~~

可直接打开页面或独立编辑器：

~~~powershell
.\rockoon-native.exe "D:\Games\Ballance" --page=maps
.\rockoon-native.exe "D:\Games\Ballance" --tas-editor project.tas
~~~

ROCKOON_NATIVE_CONFIG_DIR 可指定配置目录，用于便携使用或隔离验收。
独立 TAS 编辑器将偏好存入该目录的 tas-editor 子目录；游玩记录通过文件锁共享。

macOS 构建参见 .github/workflows/native.yml：
分别构建 Apple Silicon/Intel，使用 lipo 合并，复用 scripts/fetch-wine.mjs，
以 Zig 编译原 src-launcher/launch.c，再执行 native/scripts/bundle-macos.py。
运行本身无需 Node.js。Wine 运行时及原始许可证作为 .app 资源随包提供。

## 制图工具

资源页的“制图”入口检测本机 Blender，也可手选路径；Blender 本体通过官网下载安装，不在后台代装。
BBP 优先使用资源站的 `bbp-windows` / `bbp-macos` 存档，失败回退 GitHub，安装到 Blender 的 user_default 扩展目录，下载进度沿用任务页。
实际安装包清单校验插件 ID 和 Blender 最低版本；更新前保留旧插件，启用失败会回退，旧版 BBP 冲突需在 Blender 中先卸载。
地图右键菜单的“在 Blender 中编辑”会启用 BBP 并导入地图，使用当前游戏的 Textures，不覆盖原地图。
上游来源为 Ghomist/Rockoon `c0525ee`（2.7.2），Python 脚本见 resources/blender；检测兼容旧 Blender 的缺少扩展仓库情形，后台操作有超时并串行运行。
BBP v4.4 的实际 Windows 包为 489,661 字节，SHA-256 `bfb37f49e2f3cab6a0846c18eaabe7123bf78093d202663af79884043e95ac47`，最低 Blender 4.5.0；没有将插件打包进发行文件。

## 素材与格式复用

首页从所选游戏目录读取：

- Textures/Sky/Sky_A_Front.bmp。
- Textures/Button01_select.tga；缺失时尝试 Button01_deselect.tga。
- Textures/Font_1.tga：按 16 × 16 网格提取各按钮状态的 ASCII 字形，保留原始笔画、透明度与基线；不在发行包中捆绑游戏字库。
- 菜单按钮裁取图集左上角 256 × 64 像素，保留原始像素与透明度。
- 图片缺失时使用纯色和普通按钮；不生成替代插画。游戏目录采用替换纹理时会显示该目录中的素材。

预览使用的原版纹理已与 src-tauri/resources/vanilla/manifest.json 中的 SHA-256 对照。
原版文件恢复直接复用仓库已有 vanilla-core.zip 和清单，仅覆盖清单中 3D Entities 下的 NMO。
替换前保留备份，额外文件不删除。

内置 RockoonIO.bmodp 来自官方 [Rockoon 2.7.1 Windows 安装包](https://github.com/Ghomist/Rockoon/releases/tag/rockoon-v2.7.1)，
未执行安装程序，仅提取原有资源；64,000 字节，SHA-256：
1454de9b2bf6723b3eacedc41a6c03760b2c60fd76209e372af305685282424a。
源码仍在 src-bmodp/，更新模组时应一起核对来源和哈希。

native/core 直接编译旧版纯 Rust TDB/BRP/输入修复源码。
native/platform 的构建脚本仅适配原有 Win32/Wine 命令的宏、句柄与路径接口，不引入 Tauri。
原始后端和旧前端仍保留。

## 写入与兼容边界

- 修改游戏文件前按 Player.exe 的实际路径检查所选目录；其他目录的进程不阻拦，同目录的外部进程仍保护文件。结束游戏只针对本窗口持有的进程。
- Windows 无法读取进程路径时会说明无法确认目录，不把未知进程直接认作当前游戏；Wine 重建涉及共享环境，仍要求退出游戏。
- 文件替换先保留 .rockoon/backups 备份；批量写入失败会回退。删除使用 .rockoon/trash，可撤销本次删除。
- 拒绝路径越界、符号链接/目录联接、压缩包重复路径和超出限制的解压内容。
- TDB 修改保留其他表、未编辑选项和最新进度；配置文件如被其他操作修改，会弹出“覆盖 / 取消”，取消会重新读取外部文件。
- 旧版 WebView 的 localStorage 不会自动读取；已有游戏文件、补丁版本记录和配置方案可直接读取。
- 原版 Player 不读取 Player.ini；该入口仅在检测到 NewPlayer 时出现。
- TAS 回放要求安装 BallanceTAS 2.x，生成配置后再使用；临时改动在游戏退出后恢复，崩溃后的恢复记录会保留到下次正常启动。
- TAS 已覆盖上述功能，交互为原生实现；旧编辑器的全部绘制和手势细节不逐一复制。
- 原生自更新仅识别此 fork 的 native-v* 发布与固定产物名，拒绝上游 Tauri 安装包。首次发布原生产物前不会有可用更新。
- macOS 继续实验性维护，需要实机验证 Wine、Rosetta、URL 事件及游戏窗口表现；TAS 嵌入/回放只在 Windows 提供。
- 不恢复旧版装饰背景、轮播或辅助说明文案。
