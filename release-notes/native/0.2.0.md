这是 schtonn/Rockoon 的原生桌面版，界面使用 Rust + Iced，无需 WebView2。

## Added

- 使用游戏原版天空、球模型、平台、火焰和菜单字形的首页，支持拖动球和预览选择背景。
- 在线资源站搜索、封面预览、版本选择和安装，本地紧凑列表、模组开关与文件右键操作。
- 游戏、NewPlayer 和 BML/BML+ 的版本查看、安装与编辑，首次使用可选择已有游戏或下载安装。
- 配置、存档自动保存，外部修改冲突时选择覆盖或取消，单项撤销恢复本次编辑前的值。
- 原版及模组按键统一点击录入，Esc 取消，自动使用对应的键位编码。
- 制图工具对齐上游 2.7.2：检测或手选 Blender，安装和启用 BBP，使用当前游戏材质，从地图右键菜单打开 Blender 编辑。
- 独立 TAS 编辑器、配置集、天空盒预览与导入、后台下载任务和原版资源恢复。

## Changed

- 统一思源黑体，提供浅色与深色模式，其他页面沿用首页天空的毛玻璃底图。
- 首次使用的两个操作按钮统一高度，输入框、下拉框、Tab 与资源卡片采用半透明底色。
- 非当前目录的游戏进程不阻拦操作，文件替换保留备份，下载和安装过程集中显示在任务页。
- 消息自动消失，也可点击整条关闭。

## Removed

- 原生发行包不再依赖 Tauri、WebView2 或 JavaScript。
- 移除多余栏目、常驻保存按钮和重复的地图承载关卡设置。

Windows 下载 `Rockoon-native-windows-x64.exe` 即可使用，游戏本体需要自行选择或通过引导安装。

制图工具只检测本机 Blender，并提供官网下载入口；BBP v4.4 要求 Blender 4.5 或更新版本，优先从社区资源站下载，失败时回退 GitHub，更新失败保留原插件。

macOS 通用包为实验版本，包含既有 Wine 运行时，仍需实机验证游戏、Rosetta 和系统权限；BBP 当前仅提供 Apple Silicon 的 macOS 包。

本次校验包含原生逻辑测试和实际 BBP 安装包的只读验证，未执行界面截图测试或 Blender 实机导入测试。

制图功能参考 [Ghomist/Rockoon 2.7.2](https://github.com/Ghomist/Rockoon/commit/c0525ee)，其余原有代码与资源来源见仓库文档。
