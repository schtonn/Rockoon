Rockoon 原生桌面版 0.2.0 的核心变化是用 Rust + Iced 重写整个启动器，并围绕 Ballance 重新设计界面与使用流程。

## 修改

- **重新设计界面**：精简导航和页面层级，使用游戏原版的天空、球、平台、火焰与菜单字形，支持浅色和深色模式。
- **整合资源管理**：在启动器内搜索在线资源、查看封面、选择版本并安装，本地资源使用紧凑列表管理地图、模组、天空盒等内容。
- **重整安装与配置流程**：首次使用可选择已有游戏或下载安装，游戏页统一管理当前目录的 Ballance、NewPlayer 和 BML/BML+ 及其版本与依赖，配置、存档和配置集集中管理。
- **简化配置编辑**：修改自动保存，遇到外部文件冲突再确认，已修改的选项可逐项撤销，游戏和模组键位统一按键录入。

## 新增

- **可交互的首页场景**：三种球带随机动量落向平台，可用鼠标拖动，并能通过缩略图选择首页天空背景。
- **Blender / BBP 制图工具**：补齐上游 2.7.2 的制图功能，可检测或手选 Blender、安装并启用 BBP，从本地地图右键菜单进入编辑并使用当前游戏的材质。

## 删除

- 原生发行包移除 Tauri / WebView2 界面运行时依赖，无需安装 WebView2。

TAS 编辑器、配置集、资源包导入、天空盒预览、下载任务和原版资源恢复等原有能力继续保留。

Windows 下载 `Rockoon-native-windows-x64.exe`，首次启动后选择或安装游戏即可。macOS 通用包仍为实验版本，游戏运行依赖 Wine，BBP 的 macOS 包目前仅支持 Apple Silicon。

制图需要另行安装 Blender，当前 BBP v4.4 要求 Blender 4.5 或更新版本。

基于 [Ghomist/Rockoon](https://github.com/Ghomist/Rockoon) 开发，制图功能参考上游 2.7.2。
