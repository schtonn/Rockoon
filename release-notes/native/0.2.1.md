# Rockoon Native 0.2.1

这一版主要完善 macOS 首次使用流程、资源管理和天空盒预览。

## 新增

- macOS 首次启动会按当前状态引导安装 Rosetta、准备 Wine 和初始化游戏环境，失败后可重试，也可选择已有的 Wine。
- 本地天空盒按整组成行显示，展开后管理各张贴图，每行的菜单按钮与右键菜单提供相同操作。

## 改进

- 天空盒预览支持鼠标拖动，方向和俯仰滑块实时更新，修正俯仰方向与底部贴图接缝。
- 制图工具并入资源类型下拉框，保留在线与本地的选择状态，切回其他类型即可继续浏览资源。
- 补齐英文界面的配置字段、下拉选项、引导和提示，配置页使用 Preferences 与 Profile。
- 整理 macOS 的 Wine 设置与资源站安装链接关联，增强浅色模式的选中状态辨识度，并修正资源列表右侧控件布局。

## 删除

- 移除独立的制图切换按钮，统一从资源类型选择。

Windows 下载 `Rockoon-native-windows-x64.exe`。macOS 下载通用包，仍为实验版本，游戏通过 Wine 运行。
